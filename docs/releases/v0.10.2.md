# Orchestrator chart v0.10.2

This chart patch pins the official NATS server 2.14.9 image by immutable
multi-platform registry digest, replacing the previous 2.14.0 server default.
The Alpine image is selected explicitly. The existing
0.10.0 and 0.10.1 packages remain immutable.

NATS 2.14.9 uses Go 1.26.10 and includes upstream security and correctness fixes.
The original AMD64 and ARM64 image binaries match the official checksum-verified
release archives. Binary scans found no vulnerable package or symbol matches;
both retain one module-only OpenPGP advisory (GO-2026-5932), without its package
or symbols in these binaries. This is not a claim that all container packages
are free of vulnerabilities. See the [upstream release notes](https://github.com/nats-io/nats-server/releases/tag/v2.14.9).

Control Plane 3.3.0, Data Plane 4.2.1, IAM 2.6.0, Console 1.5.0 and Runner 3.2.0
are unchanged. The NATS Helm dependency and its archive/lock, JetStream
configuration, authentication, PVCs, resource counts and default policies remain
unchanged. No HTTP API, SDK, application binary or schema update is required;
the schema tuple remains IAM 39, Control Plane 54 and Data Plane 40.

Upgrades must explicitly select the new NATS tag and digest when retained Helm
values include the old image. Preserve custom connection, credential, storage
and replica settings. NATS must restart; a single-node installation requires
a maintenance interruption. Retain a consistent cold JetStream backup with its
authentication and authority material, verify an independent restore, and use
compatible forward recovery. Do not assume an old binary can safely reopen a
store after new writes. Historical pre-migration-40 Draft database archives
still require the staged repair described in the Data Plane 4.2.1 recovery guide.

Native JetStream restore/upgrade, final application compatibility and installed
cluster checks remain separate from source/render and upstream binary checks.
