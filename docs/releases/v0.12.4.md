# Platform Orchestrator Helm chart 0.12.4

This security patch pins Runner `3.3.1` by its qualified public image digest,
both as the deployment Runner image and as the runner gateway image. Its
bundled Infracost executable moves to `v0.10.51` with OpenTelemetry `1.47.0`
and the fixed gorilla/websocket revision, which resolves
[GO-2026-6974](https://pkg.go.dev/vuln/GO-2026-6974) and
[GO-2026-6278](https://pkg.go.dev/vuln/GO-2026-6278) there. Infracost runs only
when cost estimation is enabled, which is disabled by default; upstream
tightened some AWS price filters, so individual estimates can differ.

Runner `3.3.1` also bundles the newest official OpenTofu patch release,
`1.13.10` (from `1.13.2`). New state is written with tool version `1.13.10`.
Runner behaviour, configuration and APIs are unchanged; see the
[Runner 3.3.1 notes](https://github.com/stellwerk-labs/platform-orchestrator-runner/blob/v3.3.1/docs/releases/v3.3.1.md).

The compatible set retains Control Plane `4.1.2`, Data Plane `4.4.2`, IAM
`2.8.2`, Console `1.7.0`, CLI `2.5.1` and provider `2.4.0`. All other image pins
and configuration defaults are unchanged from `0.12.3`, and this patch runs no
migration.

For installations older than `0.12.2`, retain the applicable
[earlier upgrade and recovery requirements](v0.12.2.md), including the verified
coordinated recovery point for Core schema `57` and IAM-first ordering. Runner
`3.3.1` retains the explicitly accepted findings in its official OpenTofu
executable; its
[version-scoped disposition](https://github.com/stellwerk-labs/platform-orchestrator-runner/blob/v3.3.1/docs/releases/vendor-residuals-v3.3.1.md)
records the affected binary, findings and qualification limits.
