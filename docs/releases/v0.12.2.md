# Platform Orchestrator Helm chart 0.12.2

This patch pins Control Plane `4.1.1` by its qualified public image digest.
Observation target queries distinguish deleted identities from inactive
Environments. Grant updates can prune only exact previously granted targets
that have since been deleted, preserving the command's recorded outcome.
Deleted unstarted requests can close safely without changing accepted work or
completed history.

The compatible set retains Data Plane `4.4.1`, IAM `2.8.1`, Runner `3.3.0`,
Console `1.7.0`, CLI `2.5.1` and provider `2.4.0`. All other image pins and
configuration defaults are unchanged from `0.12.1`.

Control Plane schema `57` fences the new persisted observation responses. Take
and independently verify a coordinated database, configuration and key recovery
point before upgrading. Older Control Plane images refuse the new schema.
Once deletion-aware responses exist, rollback requires restoring the coordinated
recovery point with its matching components. Do not delete response metadata or
revert only an image or Helm revision to force a downgrade. Data Plane and IAM
schema heads remain `43` and `41`.

Upgrade Core before the separately licensed, privately delivered Drift Detection
`0.1.2` plugin. That plugin requires Core's
`environment-observation-deletion/v1` contract. The public chart does not install
commercial plugins or grant licences. This patch does not create deployment
baselines or enable Runner observation capacity. Progressive Rollouts is
unchanged.

For installations older than `0.12.1`, retain the applicable
[earlier upgrade and recovery requirements](v0.12.0.md), including IAM-first
ordering. Runner `3.3.0` retains the explicitly accepted findings in its unchanged
OpenTofu executable; its
[version-scoped disposition](https://github.com/stellwerk-labs/platform-orchestrator-runner/blob/v3.3.0/docs/releases/vendor-residuals-v3.3.0.md)
records the affected binary, findings and qualification limits.
