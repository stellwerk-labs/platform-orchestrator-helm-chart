# Orchestrator chart v0.10.0

Pins the qualified stable application set: Control Plane 3.3.0, Data Plane 4.2.0,
IAM 2.6.0 and Runner 3.2.0. Console remains 1.5.0. Image references use immutable
indexes; both Data Plane Runner jobs and the Runner gateway use the same Runner
index. Chart package identity and packaged installation qualification are separate
from the application artifact proofs.

- Route the optional versioned Environment observation and recovery APIs to the
  Control Plane. Preserve Data Plane and canonical IAM internal-only authority.
- Preserve ordinary gateway routes, workload-identity and entitlement policy,
  separate database credentials and single-writer migration strategy.
- Use the final matching IAM/CP/DP/Runner and generic runtime artifacts, not an
  available old-image fallback. No commercial plugin is installed by this chart.

The coordinated database transitions are IAM 38→39, CP 51→54 and DP 37→39. Stop
incompatible writers, preserve verified DB/role/ACL/sequence and NATS/Vault
recovery material, and rehearse restore/forward recovery before upgrade. A binary
or Helm rollback does not reverse newly classified identities or accepted receipts.

The release-specific vendor advisory disposition remains exact-artifact scoped;
it does not suppress component source/binary checks or substitute for original
artifact, signature, SBOM, provenance or packaged installation qualification.

Observation routes are disabled by default. Enable
`control-plane.gatewayApi.route.observation.enabled=true` only after qualifying the
matching server and Runner artifacts. The switch reuses the authenticated gateway
rule and does not install or license a plugin. Internal transport and IAM Admin
checks remain cluster-only.
