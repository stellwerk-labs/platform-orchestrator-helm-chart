# Platform Orchestrator Helm chart 0.12.3

This security patch pins Control Plane `4.1.2`, Data Plane `4.4.2` and IAM
`2.8.2` by their qualified public image digests. They update the OpenTelemetry
Go SDK to `1.47.0`, which fixes
[GO-2026-6974](https://pkg.go.dev/vuln/GO-2026-6974): attribute values
containing U+FFFD runes could exceed the configured attribute value length
limit. Their API, permissions, database schemas and configuration are
unchanged, and this patch runs no migration.

The compatible set retains Runner `3.3.0`, Console `1.7.0`, CLI `2.5.1` and
provider `2.4.0`. All other image pins and configuration defaults are unchanged
from `0.12.2`.

Runner `3.3.0` bundles an Infracost executable that also links GO-2026-6974
(OpenTelemetry trace auto-instrumentation spans) and
[GO-2026-6278](https://pkg.go.dev/vuln/GO-2026-6278) (gorilla/websocket mask
key generation). Infracost runs only when cost estimation is enabled, which is
disabled by default. The Runner `3.4` release candidates include both fixes.

For installations older than `0.12.2`, retain the applicable
[earlier upgrade and recovery requirements](v0.12.2.md), including the verified
coordinated recovery point for Core schema `57` and IAM-first ordering. Runner
`3.3.0` retains the explicitly accepted findings in its unchanged OpenTofu
executable; its
[version-scoped disposition](https://github.com/stellwerk-labs/platform-orchestrator-runner/blob/v3.3.0/docs/releases/vendor-residuals-v3.3.0.md)
records the affected binary, findings and qualification limits.
