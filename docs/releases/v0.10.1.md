# Orchestrator chart v0.10.1

This chart patch pins Data Plane 4.2.1 and its migration 40 restore correction.
The existing 0.10.0 package remains immutable.

The patch retains Control Plane 3.3.0, IAM 2.6.0, Console 1.5.0 and the
same Runner 3.2.0 index for both ordinary jobs and the Runner gateway. NATS 2.14.0,
its lock/archive, child charts, templates, routes and default policies are unchanged.
No HTTP API, SDK or Runner protocol update is required.

Migration 40 gives the two outer Draft validators an application-schema search
path, so new backups use the normal restore path. Historical schema 37–39 archives
containing successful Draft-test Deployments retain their old function metadata.
They require pre-data, the exact schema-qualified two-function metadata repair,
then data/post-data validation before normal migration 40. Preserve the original
archive and a failed partial target; never disable CHECKs, insert migration history
before COPY or replay a restore over the partial database.

The resulting schema tuple is IAM 39, Control Plane 54 and Data Plane 40. Retain
verified database/role/ACL/sequence, Bao, NATS, authority and state backups, and
use compatible forward recovery. A Helm rollback or migration-39 binary cannot
reverse schema 40. Packaged fresh/upgrade/native and original-artifact checks
remain separate gates; this note does not claim they have already completed.
