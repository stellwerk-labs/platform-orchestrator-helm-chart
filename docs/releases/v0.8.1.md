# Orchestrator Helm chart v0.8.1

This maintenance release pairs the Keycloak server and Operator at 26.8.1 and
adds optional Gateway external traffic policy configuration.

## Changes and application compatibility

The target application patch set is Control Plane 3.1.1, Data Plane 4.0.1,
IAM 2.5.1 and Console 1.4.1. Select the qualified public image digests from the
final release manifest. The application patches preserve API wire contracts
and the existing database schemas. Existing Runner and plugin runtime artifacts
remain separate; this chart does not clear their security holds or the
independent OpenBao hold.

The embedded Keycloak chart is 0.1.1. Keycloak Operator chart 0.1.1 includes the
upstream Keycloak, realm import, OIDC client and SAML client CRDs. Existing
v2alpha1 resources remain served alongside the new v2beta1 definitions.
Cross-namespace operation remains supported. Server and Operator images are
pinned separately by digest.

GatewayClass chart 0.1.1 adds optional `service.externalTrafficPolicy` for
NodePort and LoadBalancer services. Its default remains empty, preserving
Envoy Gateway's default. `Local` preserves client source IPs and requires a
ready proxy on every node receiving external traffic. `Cluster` forwards to
ready proxies on other nodes and can change the source IP seen by the proxy.
Review IP-based rules when choosing it. A Ready Deployment and healthy xDS do
not prove that an external NodePort reaches a proxy after rescheduling; verify
the real HTTP and TLS paths after an upgrade.

## Keycloak upgrade and recovery

Before upgrading from 26.0.x, back up the Keycloak database and configuration
and test restoration of that snapshot with the original server image. Stop
the old server before running the new one against the database. Do not run
old and new versions concurrently during migration.

Helm rollback alone does not undo the Keycloak database migration. To recover
the old version, stop the server, restore its original database snapshot and
configuration, then start the old image. Application-only rollback instructions
do not cover this migration. Follow the
[Keycloak 26.8.1 upgrade guide](https://www.keycloak.org/docs/26.8.1/upgrading/).

Back up Orchestrator databases and configuration before applying the chart.
Retain the 0.8.x application schema and use a compatible application revision
or forward repair. Database Down migrations are not a recovery procedure.

## Distribution

The Orchestrator chart package contains the embedded Keycloak server chart. The
Keycloak Operator and GatewayClass charts are also present in the immutable
`v0.8.1` source tag; they are not separate OCI publications of the Orchestrator chart
workflow. Install the paired Operator chart before upgrading the Keycloak
server. Installer profiles that vendor their own GatewayClass chart require
the matching reviewed installer update.
